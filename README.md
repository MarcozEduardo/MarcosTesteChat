# 💳 BillTracker - Agenda de Contas

Aplicação modular em React + Vite estruturada em 11 pastas.

### 📁 Estrutura de Pastas:
- `public/` - Ativos estáticos
- `src/assets/` - Ícones e vetores
- `src/components/` - Cards, Navbar e Modais
- `src/pages/` - Dashboard e Relatórios (2 páginas)
- `src/context/` - Contexto global e persistência
- `src/hooks/` - Hook customizado `useBills`
- `src/styles/` - Tema Glassmorphism cyberpunk
- `src/services/` - Seed de dados iniciais
- `src/helpers/` - Formatadores de moeda e dias
- `src/types/` - Definições de schema
- `src/config/` - Configuração de categorias e cores
